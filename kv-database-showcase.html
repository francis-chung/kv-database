KV-Database

A Lightweight Key-Value Store with Sorted Set Functionality

What is KV-Database?

KV-Database is a high-performance, Rust-based key-value database that combines the simplicity of traditional key-value stores with the power of sorted sets. Built for developers who need fast, reliable data storage with advanced querying capabilities.

Rust Tokio Async Runtime Skip Lists LRU Caching WAL Persistence Periodic Snapshots

⚡ Blazing Fast Performance

Built with Rust and powered by Tokio's asynchronous runtime, KV-Database delivers exceptional throughput with minimal latency. Features like LRU caching and skip lists ensure O(log n) lookup times for sorted sets.

🔑 Full Key-Value Functionality

Complete CRUD operations for string key-value pairs including GET, SET, DEL, EXISTS, DBSIZE, and CLEAR commands with atomic operations and WAL persistence.

📊 Sorted Set Operations

Advanced sorted set capabilities with ZADD, ZSCORE, ZREM, and ZRANGE commands. Perfect for leaderboards, priority queues, and time-series data with score-based ordering.

💾 Data Durability

Write-Ahead Logging (WAL) ensures data persistence across restarts, while periodic snapshots provide fast recovery and backup capabilities.

Available Commands

GET key

Retrieve the value associated with a key. Returns NIL if key doesn't exist.

SET key value

Set the value of a key. Overwrites existing value if key already exists.

DEL key

Delete a key and its associated value from the database.

EXISTS key

Check if a key exists in the database. Returns 1 if exists, 0 otherwise.

DBSIZE

Get the number of keys currently stored in the database.

CLEAR

Remove all keys and values from the database.

ZADD key member score

Add a member with a score to a sorted set. Updates score if member already exists.

ZSCORE key member

Get the score associated with a member in a sorted set. Returns NIL if member doesn't exist.

ZREM key member

Remove a member from a sorted set. Returns 1 if removed, 0 if member didn't exist.

ZRANGE key start stop [WITHSCORES]

Get a range of members from a sorted set by index. Optionally include scores.

How to Run KV-Database

# Clone the repository
git clone https://github.com/yourusername/kv-database.git

# Build the project
cd kv-database
cargo build --release

# Run the server
cargo run --release

# Connect using netcat or telnet
nc localhost 7878
# Or use any TCP client

# Example commands:
SET name "John Doe"
GET name
ZADD leaderboard "Alice" 1500
ZADD leaderboard "Bob" 1200
ZRANGE leaderboard 0 -1 WITHSCORES

Deploy to Vercel

While KV-Database is primarily designed as a TCP server, you can deploy a lightweight API wrapper or frontend to Vercel that connects to your hosted database instance.

# For Vercel deployment of frontend/demo
vercel kv-database-showcase.html

# Or deploy a Node.js/Go/Python API wrapper
# that connects to your TCP database server

# Example API endpoints:
GET /api/get?key=name
POST /api/set
POST /api/zadd
GET /api/zrange?key=leaderboard&start=0&stop=-1
